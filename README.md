# Qentra

Qentra is an exam-intelligence workspace focused on Bihar teacher exams, starting with STET and TRE Computer Science.

## Current MVP
- STET + TRE Computer Science tracks
- PYQ intelligence dashboard UI
- Concept dependency view
- Priority topic view
- Adaptive mock engine preview
- Responsive layout
- Persistent light/dark mode

> The analytics values currently shown in the UI are explicitly marked as illustrative placeholders. Verified PYQ data should be loaded before presenting them as factual exam statistics.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static HTTP server.
